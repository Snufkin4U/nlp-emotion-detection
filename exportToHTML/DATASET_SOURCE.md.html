# Dataset source and license

- Dataset name: **Emotions dataset for NLP**
- Kaggle owner: **Praveen Govi (`praveengovi`)**
- Kaggle URL: https://www.kaggle.com/datasets/praveengovi/emotions-dataset-for-nlp
- Kaggle dataset version used: **1**
- License shown by Kaggle: **CC BY-SA 4.0**
- Original files: `train.txt`, `val.txt`, `test.txt`

The dataset page credits Elvis Saravia and the Hugging Face team and links the following research paper describing the preparation technique:

Elvis Saravia, Hsien-Chi Toby Liu, Yen-Hao Huang, Junlin Wu, and Yi-Shin Chen. “CARER: Contextualized Affect Representations for Emotion Recognition.” EMNLP 2018. https://aclanthology.org/D18-1404/

The dataset files are included unchanged for reproducibility and educational use. Any redistribution or derivative work should follow the CC BY-SA 4.0 terms shown on Kaggle.
